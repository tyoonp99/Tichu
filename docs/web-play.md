# 사람 2명 vs Model C v2 웹 플레이 (시험판)

이 기능은 한 컴퓨터에서 게임 서버를 실행하고, 브라우저로 Model C v2와 대국하는
최소 제품 버전이다. 시작 화면에서 다음 모드를 고른다.

- **혼자 하기:** 사람 0번 + Model C v2 1·2·3번
- **친구와 하기:** 사람 0·2번 + Model C v2 1·3번

## 현재 포함된 범위

- rules-v2 엔진이 서버에서 모든 상태·합법 행동을 판정
- 각 브라우저에는 자신의 손패와 공개 정보만 전송
- Model C v2가 AI 두 자리를 자동으로 진행
- 마작 소원과 드래곤 트릭 양도는 사람에게 선택지로 표시
- 좌석별 긴 초대 토큰을 사용: 0번 링크로 2번 손패를 볼 수 없음
- 카드·패스·AI 행동을 한 번씩 표시하고, 카드가 나온 뒤 0.8초 동안 테이블에 남긴다.
- 사람이 낼 수 있는 폭탄 응답 차례에는 서버 기준 3초 카운트다운 후 자동 패스한다.

첫 버전의 간소화 사항은 다음과 같다.

- 한 **라운드**만 진행한다. 목표 점수까지 여러 라운드를 누적하는 매치 기능은 아직 없다.
- Grand Tichu/일반 Tichu 선언과 카드 교환은 자동으로 처리한다.
- 십자형 테이블에서 내 손패를 직접 선택해 낸다. 서버의 합법 조합 목록과 일치하는
  선택만 `내기`가 활성화되며, 싱글 전체 목록은 화면에 표시하지 않는다.
- 서버는 메모리에만 방을 보관한다. 서버를 재시작하면 진행 중인 방은 사라진다.

## 로컬 실행

Docker Desktop을 실행한 뒤 프로젝트 루트에서 실행한다.

```powershell
# 최초 한 번: Model C 추론용 기반 이미지를 준비
docker compose build train-bc

# 웹 서버 시작
docker compose up --build web
```

브라우저에서 [http://localhost:8080](http://localhost:8080)을 열고 **새 방 만들기**를 누른다.
혼자 하기는 바로 시작한다. 친구와 하기에서만 만든 사람은 0번 좌석이며, 화면에 표시된
**친구 초대 링크**를 그대로 친구에게 보낸다. 친구는 그 링크로 2번 좌석에 접속한다.

중지는 다음 명령으로 한다.

```powershell
docker compose stop web
```

## 원격 친구와 시험하기

서버를 실행한 PC에서 임시 터널을 열면 된다. 예를 들어 Cloudflare Tunnel을 설치한 뒤
별도 PowerShell에서 다음을 실행한다.

```powershell
cloudflared tunnel --url http://localhost:8080
```

출력된 `https://...trycloudflare.com` 주소를 브라우저로 열어 방을 만들고, 화면의 친구
초대 링크를 보낸다. 터널·웹 서버·PC가 켜져 있는 동안에만 접속할 수 있다.

초대 링크 자체가 좌석 권한이므로 공개 채팅방에 올리지 말고 친구에게만 전달한다.
