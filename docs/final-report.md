# 티츄 AI 프로젝트 최종 보고서

- 종료일: 2026-08-23
- 프로젝트 상태: 연구·실험 단계 종료
- 최종 규칙 엔진: `rules-v2`
- 최종 정책: Model C v2 (`models/model-c-v2/model-c.pt`)

## 1. 요약

이 프로젝트는 공식 티츄 규칙을 재현하는 게임 엔진을 검증하고, 공개 인간 대국 로그로
합법 행동 정책을 학습한 뒤, 동일 카드 분배와 좌석 교환 조건에서 여러 에이전트를 비교하는
것을 목표로 진행했다.

최종 결과는 Set Attention 손패 인코더와 Bi-GRU 트릭 인코더를 결합한 **Model C v2**다.
Model C v2는 독립 test 결정 650,605건에서 Top-1 88.20%, Top-3 98.62%를 기록했다.
실제 게임 형식의 내부 벤치마크에서는 Baseline B보다 평균 +39.10점, Fuegi-MCTS보다
평균 +196.50점 앞섰다.

BC-guided MCTS와 PPO 자기대전도 구현·평가했으나 Model C v2를 안정적으로 개선하지
못했다. 실제 트릭 점수를 중간 보상으로 사용한 Dense Reward PPO는 오히려 통계적으로
유의한 성능 하락을 보였다. 따라서 강화학습 후보는 승격하지 않고 연구를 종료한다.

이 결과는 **프로젝트 내부 에이전트 중 Model C v2가 가장 강하다**는 근거다. 사람과 직접
대국한 평가가 없으므로 인간 실력 등급이나 인간 대비 승률을 주장하지 않는다.

## 2. 규칙 엔진과 검증

초기 엔진에서 카드 조합, 점수 계산, 상태 전이의 회귀 테스트를 구축하고 다음 규칙을
보완했다.

- 비동기 폭탄과 재폭탄
- 피닉스의 동적 높이 및 복합 조합
- 마작 소원 이행
- 드래곤 트릭 양도
- 더 높은 풀하우스 및 희귀 조합 비교
- 종료 순위, 더블 승리, 라운드 점수 정산

Brettspielwelt 완전 게임 10,000개를 수집해 rules-v2 엔진으로 재생했다. 원본 96,257라운드
중 미완성 488개를 제외한 95,769라운드가 행동과 최종 점수 모두 일치했다. 완료 라운드의
불법 행동과 점수 불일치는 각각 0건이었다. 인간 로그는 테스트 예시를 넘어 규칙 엔진의
실제 반례를 발견하는 검증 자료로 사용됐다.

## 3. 인간 대국 데이터셋

검증된 로그에서 행동자가 실제로 볼 수 있는 정보, 합법 행동 목록, 인간의 선택을 스키마
v2로 변환했다. 플레이어 이름은 제외하고 원본 게임 ID는 가명화했다. 같은 게임이 여러
분할에 섞이지 않도록 게임 단위로 80/10/10 분할했다.

| 분할 | 결정 수 |
|---|---:|
| train | 5,209,033 |
| validation | 682,767 |
| test | 650,605 |
| 합계 | 6,542,405 |

선택 행동이 합법 행동 목록에 포함되는지 전수 검사했고, 분할 간 게임 ID 중복은 0건이었다.
두 번의 전체 생성에서 데이터와 manifest의 SHA-256도 일치했다. 실제 폭탄 42,505개와
추론된 폭탄 보류 문맥 1,175,358개는 별도로 구분했다.

## 4. 지도학습 모델 선택

첫 강한 기준선인 Baseline B는 상태 벡터와 각 합법 행동을 MLP로 점수화했다. 이후 Model C는
손패를 순서 없는 집합으로 처리하는 Set Attention, 현재 트릭의 행동 순서를 처리하는 Bi-GRU,
공개 상태 인코더와 합법 행동 후보 점수기를 결합했다. 불법·패딩 후보의 logit은 음의 무한대로
마스킹했다.

Model C v1은 전체 정확도는 개선했지만 희귀한 폭탄 판단이 악화됐다. Model C v2에서는 폭탄,
Pair, FullHouse에 가중 Cross-Entropy를 적용해 전체 성능을 유지하면서 해당 약점을 회복했다.

최종 test 결과는 다음과 같다.

| 지표 | 결과 |
|---|---:|
| 전체 Top-1 | 88.20% |
| 전체 Top-3 | 98.62% |
| Cross-Entropy loss | 0.3116 |
| 폭탄 Top-1 | 70.14% |
| Pair Top-1 | 76.12% |
| FullHouse Top-1 | 73.38% |
| 피닉스 포함 행동 Top-1 | 61.20% |
| 피닉스 보유 상황 Top-1 | 84.16% |

validation과 test 결과가 거의 일치해, 모델 선택 과정에서 관찰한 성능이 독립 분할에서도
유지됐다.

## 5. 실제 게임 벤치마크

모든 본 평가는 같은 seed를 두 번 실행하고 두 번째 게임에서 팀 좌석을 교환했다. 빠른 반복을
위해 목표 점수는 200점으로 설정했으며, 승패뿐 아니라 평균 점수 차와 seed 쌍별 95% 신뢰구간을
기록했다.

| 상대 | 실제 게임 | Model C v2 전적 | 평균 점수 차 | 쌍별 95% CI |
|---|---:|---:|---:|---:|
| Baseline B | 400 | 242승 151패 7무 | +39.10 | +26.69~+51.51 |
| Fuegi-MCTS, 고정 10회 | 400 | 385승 14패 1무 | +196.50 | +188.55~+204.45 |

두 비교 모두 신뢰구간 전체가 0보다 커 Model C v2의 우세가 확인됐다. 다만 Fuegi-MCTS는
탐색 횟수가 작고 기존 휴리스틱 성능도 제한적이므로, 이 결과를 인간 고수 대비 성능으로
확대 해석하지 않는다.

## 6. 승격하지 않은 접근

### BC-guided MCTS

Model C의 행동 확률을 PUCT prior로 사용했다. 동일 조건에서 Fuegi-MCTS는 이겼지만,
신경망 추론 비용 때문에 탐색량이 줄어 단독 Model C보다 약했다. prior batching, 캐시 또는
탐색 구조 개선 없이는 실용적 이점이 없다고 판단했다.

### PPO 자기대전

Model C v2에서 초기화한 Actor-Critic, GAE, KL anchor, 동결 상대와 과거 스냅샷 상대 풀을
구현했다. rollout을 최대 4,096게임까지 확대했지만 C v2 대비 평가 신뢰구간은 계속 0을
포함했고, 일관된 개선 추세가 없었다.

마지막으로 실제 트릭 점수의 25%를 중간 보상으로 주는 Dense Reward를 실험했다. 256게임 뒤
평가에서 22승 37패 1무, 평균 -35.33점, 95% CI -58.83~-11.84를 기록해 조기 종료했다.
단기 트릭 점수는 폭탄 보존, 파트너 지원, 피닉스 보류처럼 장기적으로 가치 있는 선택과 충돌할
수 있다. 현재 데이터·보상·탐색 규모에서는 PPO가 강한 인간 모방 정책을 개선하지 못한다는
결론으로 강화학습 실험을 종료했다.

## 7. 프로젝트가 입증한 것과 한계

입증한 내용:

- rules-v2가 수집한 완료 인간 로그를 불법 행동과 점수 불일치 없이 재생한다.
- 인간 대국 654만 결정을 재현 가능한 방식으로 분할·학습할 수 있다.
- Model C v2가 독립 test에서 인간 선택을 높은 정확도로 모방한다.
- Model C v2가 동일 seed·좌석 교환 내부 벤치마크에서 Baseline B와 Fuegi-MCTS보다 강하다.
- 현재 구현의 BC-guided MCTS와 PPO는 단독 Model C v2를 개선하지 못한다.

입증하지 않은 내용:

- Model C v2의 인간 상대 승률이나 객관적인 인간 실력 등급
- 목표 1,000점의 장기 실제 티츄 경기에서의 성능
- 음성·심리전·사람별 전략 적응과 같은 실제 대국 요소
- 수집 로그 참가자 전체의 실력 수준과 데이터 선택 편향

행동 모방 정확도는 인간과 같은 행동을 선택하는 정도이며, 그 자체가 승률을 보장하지 않는다.
실제 인간 상대 강도를 측정하려면 사람 1명과 봇 3명이 참여하는 플레이 가능한 UI, 대국 로그,
충분한 수의 좌석 교환 인간 평가가 별도로 필요하다.

## 9. 종료 결론

프로젝트의 연구 목표는 달성했다. 규칙 엔진, 인간 로그 데이터셋, 지도학습 정책, 공정한
벤치마크, 탐색 결합 및 자기대전의 성공·실패 결과가 모두 재현 가능한 형태로 남았다.

최종 모델은 **Model C v2**로 동결한다. 추가 연구 실험은 진행하지 않는다. 이후 작업을 다시
시작한다면 모델 튜닝의 연장이 아니라, 사람이 실제로 플레이하고 평가 데이터를 남길 수 있는
로컬 싱글 플레이 UI를 별도 제품 단계로 정의하는 것이 적절하다.
